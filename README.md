# Kibana

Die Integration kann auf die üblicher Art und Weiße durchgeführt werden.

## Kibana Template
Bezieht sich auf die Datei export_template_complete.ndjson. Hierbei handelt es sich um den Export unserer Integration von Ilias-Logs in Kibana.

## Dashboard Template
Ist in der Datei export_dashboard.ndjson gespeichert. Dabei handelt es sich um ein exportiertes Dashboard welches die Ilias-Logs Visualisiert.
